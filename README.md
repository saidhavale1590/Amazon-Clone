# Amazon Homepage UI Clone 🛒📦

A visually precise and clean clone of the **Amazon Homepage UI**, crafted entirely from scratch using **HTML5** and **CSS3**. This project focuses strictly on replicating Amazon's iconic layout, component design, and typography to practice modern front-end layout styling techniques.

---

## ✨ Features

* **Amazon Navigation Bar:** Replicates the signature dark header including the logo, location selector, search input drop-down, country selector, sign-in panel, returns tracker, and cart icon.
* **Sub-Navigation Menu:** Clean secondary navbar displaying "All" categories, today's deals, customer service, registry, gift cards, and sell options.
* **Hero Image Slider & Overlay:** Implements the classic background fade-out hero section featuring a promotional banner card layout overlay.
* **Product Grid Layout:** Modern card system grouping various shopping categories (electronics, fashion, home decor, etc.) using clean CSS flexbox/grid alignments.
* **Dynamic Hover Effects:** Micro-interactions on all links, dropdown selectors, buttons, and text fields to replicate the realistic Amazon shopping experience.
* **Multi-Tiered Footer:** Includes the "Back to top" button, standard site directory columns, localized language selectors, and copyright disclaimers.

---

## 🛠️ Tech Stack

* **HTML5:** For semantic page structure and building complex modern block element layouts.
* **CSS:** For customized grids, flexible flexbox boxes, color gradients, and transitions.
* **FontAwesome Icons:** For integrating precise design assets like the shopping cart, search magnifying glass, and navigation pin icons.

## 💻 Getting Started

Follow these fast steps to open and modify the project locally:

### Prerequisites
You only need a modern web browser installed (e.g., Google Chrome, Microsoft Edge, Mozilla Firefox) and a code editor like VS Code.

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd Amazon-Clone
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to run it in your browser, or open the folder directly in your code editor using a tool like the "Live Server" extension.
